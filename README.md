# VirtualRoom — контроль участников

Chrome-расширение сравнивает заранее сохранённый список с участниками открытой комнаты VirtualRoom. Можно создать несколько именованных списков для разных мероприятий и привязать каждый к своей комнате. Отсутствующие появляются отдельным разделом **«Не пришли»** прямо в штатном списке участников.

## Установка

1. Откройте в Chrome страницу `chrome://extensions`.
2. Включите **Режим разработчика** в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите эту папку: `C:\Users\nadra\Documents\Meetups counter`.
5. Если VirtualRoom уже была открыта, обновите вкладку.

## Использование

1. Нажмите значок расширения.
2. Нажмите **+ Новый**, задайте название мероприятия и вставьте ожидаемых участников — по одному человеку на строку.
3. При необходимости включите **Автоматически выбирать для этой комнаты**.
4. В комнате откройте штатную панель **«Участники»**.
5. Нажмите **Проверить сейчас**.

Списки можно создавать, редактировать, удалять и выбирать повторно. В заголовке раздела **«Не пришли»** есть шестерёнка: она открывает редактор прямо на странице VirtualRoom. В нём можно выбрать готовый список, дописать в него людей или создать новый. Опция **Запомнить выбор для этой комнаты** создаёт или меняет привязку к текущему адресу комнаты.

Настройка **Подсвечивать пришедших пользователей** добавляет зелёную точку слева от аватара каждого участника, найденного в выбранном списке. Подсветку можно включать и выключать как в основном окне расширения, так и через шестерёнку. Счётчик раздела **«Не пришли»** отображается в формате `отсутствуют/ожидаются`, например `0/11`.

Для отсутствующего участника можно нажать на круг с инициалами и выбрать статус: **🌴 В отпуске** или **🚌 Отсутствует**. Эмодзи заменит инициалы в круге. Статус сохраняется внутри именованного списка и будет показан при использовании этого списка в другой комнате; пункт **Без статуса** возвращает инициалы.

Статус можно задать **без срока**, **на сегодня**, **на завтра** или на произвольный период **с даты по дату**. Обе границы периода включаются. После окончания периода статус автоматически удаляется; открытая вкладка перепроверяет сроки после наступления полуночи. Если участник со статусом пришёл в комнату, его зелёная точка остаётся кнопкой — через неё статус можно изменить или снять прямо в списке активных.

Текущий срок отображается прямо в меню рядом со статусом в компактном формате, например `30.06–14.07`, и полностью — во всплывающей подсказке. При смене типа статуса даты предыдущего типа сбрасываются.

В том же меню есть пункт **Выбрать псевдоним**. Он показывает пользователей комнаты, которые ещё не совпали ни с одним именем или псевдонимом списка. Например, `Lipanti Nick` можно связать с ожидаемым участником `Липатников Никита`: после этого оба имени считаются одним человеком. Связи сохраняются внутри списка и работают в других комнатах. Удалить ошибочный псевдоним можно в редакторе списка по шестерёнке.

Стрелка возле заголовка **Не пришли** сворачивает и разворачивает строки отсутствующих, не скрывая счётчик. В основном окне расширения флажок **Подробный редактор** переключает представление списка: вместо многострочного текста появляются отдельные карточки участников с полями имени, статуса, срока и псевдонимов. Между быстрым и подробным режимами можно переключаться без потери данных.

Расширение сохраняет списки и привязки комнат локально в профиле Chrome. Регистр букв, лишние пробелы, `е/ё` и порядок слов не влияют на сравнение: `Иван Иванов` совпадёт с `Иванов Иван`.

## Замечания

- Панель участников должна быть открыта во время проверки.
- Список VirtualRoom виртуализирован. Расширение быстро прокручивает его, чтобы прочитать не только видимые строки, а затем возвращает прежнюю позицию.
- Комната определяется по полному адресу без фрагмента после `#`. Если каждая комната имеет уникальный URL, нужный список будет подбираться автоматически.
- Сейчас расширение запускается на всех обычных веб-страницах, потому что точный домен VirtualRoom не был указан. После проверки поле `matches` в `manifest.json` можно сузить до домена вашей системы.
- Если разработчики VirtualRoom изменят названия DOM-классов `ParticipantName` или `ParticipantListContainer`, селекторы в `content.js` потребуется обновить.
